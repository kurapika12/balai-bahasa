# SIPK - Sistem Informasi Pelaporan Kegiatan

## Seminar Inovasi Digital 2026

Sistem Informasi Pelaporan Kegiatan (SIPK) merupakan aplikasi berbasis web yang dirancang untuk membantu pengelolaan laporan kegiatan secara terpusat melalui fitur Approval Workflow dan Auto Summary Generator berbasis AI.

### Fitur Utama
- Manajemen Kegiatan dan Penugasan
- Pengarsipan Laporan Terpusat
- Approval Workflow
- Auto Summary Generator (Gemini AI)
